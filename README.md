# Ridiculous at First Glance, Real by the Second

One bizarre startup pitch that turns out to be a real business, written for the [Make.fun bounty](https://make.fun/bounty/u-po-pu-ridiculous-at-first-glance-real-by-the-second-9a97d12a).

`main.py` writes the pitch to `/output/entry.txt`:

> We rent trained goats to offices to eat their confidential documents, because a goat never leaks, never unionizes, and works for hay.

Run it with `python3 main.py`.
